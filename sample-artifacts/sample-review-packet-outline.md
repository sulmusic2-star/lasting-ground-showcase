# Sample Review Packet Outline

This is a simplified public-safe outline. It is not a real property report.

## 1. Front Page

- property/address label
- review date
- support depth label
- plain-English disclaimer
- source-backed scope summary

## 2. What The Packet Found

- source-backed context bullets
- relevant public/official source categories
- uncertainty and missing-source flags

## 3. Local Source Context

- town/regional context
- relevant board/source systems
- public records surfaces reviewed

## 4. Environmental / Coastal / Site Context

- public/regional layers where applicable
- source links and dates
- no unsupported engineering conclusions

## 5. Review Routing Context

- what public systems may matter
- what the reader may need to verify with qualified professionals or public offices
- no legal/permit advice

## 6. Source Appendix

- source names
- source URLs
- reviewed dates
- what each source does and does not support

## 7. Uncertainty Notes

- unavailable lanes
- source gaps
- stale records
- conflicts or ambiguity
